# Caesar_Cipher

##Projekti idee:
Programm võimaldab kasutajal salajasi sõnumeid kirjutada, krüpteerida, dekrüpteerida ning proovida tundmatu võtmega sõnumeid lahti murda.
## Tööjaotus:
1. inimene - Šifreerimine ja dešifreerimine
1.1.Kasutaja saab sisestada sõnumi.
1.2. Saab valida šifreerimisvõtme (nihke 1–25).
1.3. Programm krüpteerib ja dekrüpteerib sõnumeid.
1.4. Säilitab tühikud, numbrid ja kirjavahemärgid.
1.5. Võimaldab salvestada šifreeritud sõnumi tekstifaili.
2. inimene - Šifri lahtimurdamine
2.1. Kasutaja sisestab tundmatu võtmega šifreeritud sõnumi.
2.2. Programm proovib automaatselt kõiki 25 võimalikku nihet.
2.3. Kuvab kõik võimalikud dekrüpteeritud variandid.
2.4. Proovib tuvastada kõige tõenäolisema algse sõnumi, võrreldes tulemusi tuntud sõnadega.
2.5. Võimaldab lugeda šifreeritud sõnumit tekstifailist.
